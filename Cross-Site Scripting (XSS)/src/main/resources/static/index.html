Content Security Policy (CSP)

Una cabecera HTTP que indica al navegador que fuentes de scripts estan autorizadas. Al establecer script-src 'self', los scripts inline inyectados por un atacante son bloqueados automaticamente por el navegador, sin importar si el HTML los contiene.

Cabecera recomendada

Content-Security-Policy: default-src 'self'; script-src 'self';
  • script-src 'self' — Solo permite ejecutar archivos .js del mismo origen.
  • Scripts inline como <script>alert(1)</script> son rechazados.
  • Conexiones externas como fetch('https://attacker.com/...') son bloqueadas.

CSP es una medida de "Defensa en Profundidad": si la sanitizacion falla, el navegador bloquea la ejecucion como segunda barrera.
